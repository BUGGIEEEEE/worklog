1. 기록의 단위 Worklog가 무엇을 어디에 적는가

프로젝트 폴더/
└── .worklog/                 프로젝트마다 하나 (첫 기록 때 생성)
    └── works/                작업마다 폴더 하나
        ├── guide/            작업 1  종이 노트 습관 계획
        │   ├── events.jsonl    이력
        │   └── state.md        현재 상태
        ├── report/           작업 2  보고서 작성
        ├── api-docs/         작업 3  API 문서 정리
        └── …/                작업 n
events.jsonl · 이력모든 결정·결과를 순서대로 · 덧붙이기만, 지우지 않음
state.md · 현재 상태지금 유효한 목표·결정·제약·다음 할 일 · events.jsonl에서 계산해 저장한 사본 · ② 주입의 현재 작업 부분과 같은 내용 (5절)
작업과 기록의 관계
작업 단위작업마다 폴더 하나 · 다른 작업의 결정·제약은 섞이지 않음 · 세션은 작업 1~n 중 하나에 연결됨 (2절)
이력·현재
  • 저장할 때마다 이력에 한 줄 추가
  • 현재 상태는 이력에서 다시 계산
  • 값을 바꾸면 이전 결정은 이력에 남고 현재 상태에는 최신만
보는 법AI에게 현재 작업 상태 보여 줘 · 파일로는 state.md · 모델은 세션 시작 때 자동으로 받음 (4·5절)
