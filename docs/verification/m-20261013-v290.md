- **B(상위 작업 기록)**: Claude 3/3은 1턴에 기록 1건, Codex는 1차 2회 기록·2차 2회 skip. 둘 다 허용 경로. 1턴 시점에는 하위 작업 id가 아직 없어 모델은 제목·탭으로 지칭한다(규칙의 `<id>`는 사실상 제목).
